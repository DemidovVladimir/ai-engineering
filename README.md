# AI Engineering Booking Demo

Демонстрационный проект для ролика: один и тот же сервис записи строится двумя способами.

1. `prompts/01-single-agent.md` — один расширенный запрос агенту.
2. `prompts/02-orchestrated-workflow.md` — TDD-цикл с архитектором, исполнителем и независимым валидатором.

## Как использовать

Сначала создайте приложение в ветке `single-agent` с первым промптом. Затем вернитесь к `main`, создайте ветку `orchestrated-tdd` и запускайте второй сценарий по одной задаче за раз. Не запускайте два сценария в одной ветке: так сравнение останется честным.

До реализации прочтите `AGENTS.md`, `docs/specification.md`, `docs/architecture.md` и `docs/protocol.md`.

## Продукт

Сервис записи на встречу: просмотр свободных слотов, бронирование, отмена и фиксация события уведомления. В проекте намеренно нет реальных платежей, писем или секретов.
